# Development Roadmap

| Version | Goal |
| --- | --- |
| V0.1 | Board renders correctly |

| V0.3 | Dice + legal token movement |
| V0.4 | Full Normal Ludo rules |
| V0.5 | Polished dice/token/capture animations |
| V0.6 | Complete local 2–4 human player game |

| V0.8 | All four powers + animations |

## First implementation sprint

1. Create the project foundation and architecture.
2. Finalize the complete Normal + Power rule specification.
3. Define Player, Token, BoardCell, GameState, and GameConfig.
4. Map the full Ludo board mathematically.
5. Render the responsive board with all 16 tokens in starting positions.

Online multiplayer is intentionally deferred until the local game engine is stable and thoroughly tested.
