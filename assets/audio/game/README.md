# Ludo Global Gameplay Audio

The WAV files in this directory are original synthesized sound effects created
specifically for Ludo Global. They are not copied, sampled, traced, or extracted
from Ludo World, another game, or a third-party sound library.

Files are intentionally short, mono, and low-overhead for mobile gameplay.
