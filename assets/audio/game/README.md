# Ludo Global Gameplay Audio

Most WAV files in this directory are original synthesized sound effects created
specifically for Ludo Global. They are not copied, sampled, traced, or extracted
from another game.

## Real dice roll

`dice_roll_real.mp3` is the Kenney **Casino Audio** `dice-throw-1` sound.
It is used for the normal dice throw because the recording already includes the
physical throw, clatter, bounce, and settle that match the gameplay animation.

- Source: https://kenney.nl/assets/casino-audio
- License: Creative Commons CC0 1.0
- Attribution: not required
- Runtime length: approximately 0.68 seconds

The original synthesized `dice_roll.wav` and `dice_land.wav` are retained as
fallback/source assets, but the gameplay roll event uses
`dice_roll_real.mp3`.
